
# SPS AI Assistant

An independently developed SPS-branded AI-powered
interview and professional conversation assistant.

## Architecture

- Frontend: Next.js, React, TypeScript, Tailwind CSS
- Backend: Node.js, Express.js
- Database: MongoDB, Mongoose
- Real-time: Socket.IO
- Desktop: Electron

## Applications

- frontend: Web application
- backend: REST API and real-time services
- desktop: Windows and macOS desktop application

## Development

Start the backend:

cd backend
npm install
npm run dev

Start the frontend:

cd frontend
npm install
npm run dev

## Environment

Configure environment variables using the
.env.example files in each application.
